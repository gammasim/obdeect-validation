The optics bypass chain (`chain_optics`) takes `--telescope`, `--site`, `--input`, `--zenith` and `--azimuth`. Eight new `chain.optics-bypass1-*` cases run other telescopes (MST, SST), zenith angles, azimuths and showers (proton, South). The trigger is compared with an exact McNemar test on the discordant events, not with a zero-mismatch count.
