A sim_telarray run whose log reports a skipped or unreadable input block ("I/O block is skipped", "Cannot extend I/O buffer", "Error reading") is now an error. sim_telarray drops event blocks larger than its input buffer (`CORSIKA_IO_BUFFER`, `MAX_BUNCHES`) and still exits 0, which gave an empty camera instead of a failure. The flasher-secondary comment and the 2026-11-14 report now give this cause instead of extended block headers.
